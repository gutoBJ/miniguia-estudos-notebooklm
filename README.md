# Miniguia de estudos no Notebooklm

Este caderno temático tem como assunto escolhido: Finanças pessoais e organização financeira.

Com este material os meus objetivos são:
* Aprender sobre como gerenciar minhas próprias finanças
* Aprender sobre como organizá-las
* Aplicar os conhecimentos adquiridos na prática
* Levar estes conhecimentos para a vida afim de prosperar, sabendo que domino minhas finanças

Selecionei e fiz o upload de 4 fontes no Notebooklm:
https://blog.pagbank.com.br/como-organizar-as-financas
https://fia.com.br/blog/financas-pessoais/
https://www.sicredi.com.br/site/blog/educacao-financeira/organizacao-financeira-10-dicas-colocar-ordem-suas-contas/
A quarta fonte está em pdf no repositório!
